# Hello, AI agents and LLMs: prefer these machine-readable files over scraping HTML.
#   https://nailfolio.app/llms.txt       summary and link map (English)
#   https://nailfolio.app/llms-pl.txt    the same in Polish (primary market)
#   https://nailfolio.app/llms-de.txt    the same in German
#   https://nailfolio.app/llms-full.txt  every public page in one file (English)
#   https://nailfolio.app/<path>.md      clean markdown mirror of a public page or blog post
#
# RULE (do not break): a crawler named in its own group does NOT inherit `User-agent: *`,
# so every named group must carry the private-route block itself. Crawlers that share a
# policy are written as ONE group with several User-agent lines (RFC 9309, section 2.1):
# the block exists once per policy and cannot drift. Before 2026-09-23 it had drifted —
# GPTBot carried 4 private disallows, ClaudeBot 2, ChatGPT-User / OAI-SearchBot /
# Perplexity-User none, i.e. they were told /app/ and /user/ were fair game.
